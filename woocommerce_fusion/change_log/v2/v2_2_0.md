# WooCommerce Fusion Version 2.2.0 Release Notes


### Batch API mode will become the default

Batch API mode groups sync operations into batched WooCommerce API calls instead of sending
them one at a time, which significantly reduces load on your WooCommerce server.

- It is currently opt-in, per server: **WooCommerce Server** > **Enable Batch API**
- In a future release it will become the **default** for all servers, and the current
  one-at-a-time mode will be **deprecated**
- Queued and flushed operations are visible on the **WooCommerce Sync Status** page

Please enable it on your servers and report any issues.
